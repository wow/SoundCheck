# sc-io

The file layer: decoding through symphonia (with encoder delay applied for MP3/AAC), the exact WAV/RF64/AIFF/AIFF-C reader `iff` (chunk table with header offsets, payload ranges, pad bytes and trailing bytes; `ds64` sizes; `fmt `/`COMM`+`SSND` format; streaming PCM in 4096-frame blocks, integers at their valid bit depth with non-zero padding bits counted, floats bit-exact; chunks past a stale container size are walked and marked; a trailing ID3v1 tag is a hard end; odd chunks without their pad byte are detected by following the chain of headers), the IFF render `render::apply_iff` (WAV/RF64 -> RIFF/WAVE, AIFF/AIFF-C -> FORM/AIFF; plain-PCM `fmt ` and 18-byte `COMM`; audio through `sc_dsp::Requantiser` at 16 or 24 bits with a BLAKE3 tee hash of the written PCM; `cue `/`smpl`/`MARK` positions shifted by a head trim, PCM `fact` and `bext` TimeReference/loudness patched, `ds64`/`FVER`/float `fact` dropped, every other chunk and the trailing bytes carried byte for byte with their pad byte; refusals for more than two channels, rates other than 44.1/48 kHz, outputs past 4 GiB, peaks at full scale after gain, data in padding bits, a trim that cuts a sampler loop; streamed in 4096-frame blocks, output created new and removed on any error), and, as they land, the byte-preserving tag-block/FLAC/MP3-global-gain writers, the write transaction with backup and journal, the analysis cache and the rekordbox XML and CSV writers.
Invariants: readers never modify files; writers carry every unknown chunk, frame and block verbatim; a write is atomic or it did not happen.

Tests: `tests/matrix.rs` is the file-layer fixture matrix. It builds 24 small synthetic WAV/RF64/AIFF/AIFF-C/FLAC files in code (fixed seeds) and lists every chunk, ID3 frame, FLAC block, Vorbis field and leading/trailing tag with its SHA-256 and expected fate: carried, patched (positions shifted by a head trim, `bext` loudness), replaced or dropped. An independent reader checks them against `tests/fixtures/golden/file-layer-matrix.json` (`UPDATE_GOLDEN=1` rewrites it), and a reference writer proves the output checks accept a correct result and reject each injected mistake. The IFF writer tests run the matrix grid (0/-3.2/+2.1 dB x no trim/441 samples x loudness) and the bit-depth rows through `render::apply_iff` in every `cargo test`, and the manifest's `outputs` section pins the SHA-256 of every IFF output (or `refused`); the ID3-edit and FLAC writer tests stay `#[ignore]`d and need `SC_FILE_WRITERS=1` until those writers exist. `tests/matrix/walker.rs` checks that `iff` lists the same chunks as the independent parser and reads the generated samples on every IFF fixture; `tests/iff_fuzz.rs` runs proptest (256 cases each, `PROPTEST_CASES` for more) on random chunk soups and on random, truncated and mutated files through a reader that fails on any access past the end; `benches/iff.rs` measures walk + PCM on a 6-minute 24-bit stereo WAV, `benches/apply.rs` a -3.2 dB render of the same file from disk to disk. Known decoder quirks the writers must handle (`iff` reads RF64 itself): symphonia 0.6.1 does not read RF64 and drops the last FLAC frame when an ID3v1 tag follows it; hound 3.5 ignores RIFF pad bytes; lofty 0.25 misreads RF64.
