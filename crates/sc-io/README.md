# sc-io

The file layer: decoding through symphonia (with encoder delay applied for MP3/AAC), the exact WAV/RF64/AIFF/AIFF-C reader `iff` (chunk table with header offsets, payload ranges, pad bytes and trailing bytes; `ds64` sizes; `fmt `/`COMM`+`SSND` format; streaming PCM in 4096-frame blocks, integers at their valid bit depth with non-zero padding bits counted, floats bit-exact; chunks past a stale container size are walked and marked; a trailing ID3v1 tag is a hard end; odd chunks without their pad byte are detected by following the chain of headers), the IFF render `render::apply_iff` (WAV/RF64 -> RIFF/WAVE, AIFF/AIFF-C -> FORM/AIFF; plain-PCM `fmt ` and 18-byte `COMM`; audio through `sc_dsp::Requantiser` at 16 or 24 bits with a BLAKE3 tee hash of the written PCM; `cue `/`smpl`/`MARK` positions shifted by a head trim, PCM `fact` and `bext` TimeReference/loudness patched, `ds64`/`FVER`/float `fact` dropped, every other chunk and the trailing bytes carried byte for byte with their pad byte; refusals for more than two channels, rates other than 44.1/48 kHz, outputs past 4 GiB, peaks at full scale after gain, data in padding bits, a trim that starts inside a sampler loop, more than 16 MiB of chunks to rewrite, an AIFF past 2 GiB (signed `ckSize`); streamed in 4096-frame blocks, output created new and removed on any error or cancellation; read errors name the input, write errors the output), the ID3 editor `id3` (ID3v2.3/2.4 per id3.org: `parse_tag` indexes header, extended header and frames by byte range without decoding bodies except `TXXX` descriptions in encodings 0-3; `edit_tag` replaces frames whose label SoundCheck writes (`TBPM`, `TXXX:<name>` case-insensitive) in place and appends the rest once, keeps every other frame's bytes, version, revision and flags, reuses padding before growing the tag with 1 KiB of fresh padding, updates a v2.3 extended header's padding size and a v2.4 footer; ISO-8859-1 for ASCII text, else UTF-16 (v2.3) or UTF-8 (v2.4); tags up to 16 MiB; a tag with two copies in one file, tag-level unsynchronisation, undefined flags, an extended-header CRC or restrictions, another version, a broken structure (including a footer that does not repeat the header, and a v2.4 tag whose last binary frame also reads consistently with a plain 32-bit size, as old iTunes versions wrote them), or, for `TXXX` edits, a `TXXX` frame whose description cannot be read (compressed, encrypted, unknown encoding) is carried unchanged and reported as `NotEditable`; UTF-16 descriptions without a byte-order mark match in either byte order; `render::apply_iff` uses it for `RenderRequest.tag_edits` and never creates a tag in a file without one), and, as they land, the byte-preserving tag-block/FLAC/MP3-global-gain writers, the write transaction with backup and journal, the analysis cache and the rekordbox XML and CSV writers.
Invariants: readers never modify files; writers carry every unknown chunk, frame and block verbatim; a write is atomic or it did not happen.

Tests: `tests/matrix.rs` is the file-layer fixture matrix. It builds 24 small synthetic WAV/RF64/AIFF/AIFF-C/FLAC files in code (fixed seeds) and lists every chunk, ID3 frame, FLAC block, Vorbis field and leading/trailing tag with its SHA-256 and expected fate: carried, patched (positions shifted by a head trim, `bext` loudness), replaced or dropped. An independent reader checks them against `tests/fixtures/golden/file-layer-matrix.json` (`UPDATE_GOLDEN=1` rewrites it), and a reference writer proves the output checks accept a correct result and reject each injected mistake. The IFF writer tests run the matrix grid (0/-3.2/+2.1 dB x no trim/441 samples x loudness) and the bit-depth rows through `render::apply_iff` in every `cargo test`, and the manifest's `outputs` section pins the SHA-256 of every IFF output (or `refused:<error kind>`, and the tests assert that kind); the ID3-edit test runs every IFF fixture with `TBPM`, `TXXX:BPM`, ReplayGain and `SOUNDCHECK` edits (its outputs for the tagged fixtures are pinned in the manifest too); the FLAC writer test stays `#[ignore]`d and needs `SC_FILE_WRITERS=1` until that writer exists. `src/id3` has unit tests per module and a proptest over random frame lists and padding sizes (every other frame byte-identical and in order, the edited tag re-parses, a second identical edit changes nothing). `tests/matrix/walker.rs` checks that `iff` lists the same chunks as the independent parser and reads the generated samples on every IFF fixture; `tests/iff_fuzz.rs` runs proptest (256 cases each, `PROPTEST_CASES` for more) on random chunk soups and on random, truncated and mutated files through a reader that fails on any access past the end; `benches/iff.rs` measures walk + PCM on a 6-minute 24-bit stereo WAV, `benches/apply.rs` a -3.2 dB render of the same file from disk to disk. Known decoder quirks the writers must handle (`iff` reads RF64 itself): symphonia 0.6.1 does not read RF64 and drops the last FLAC frame when an ID3v1 tag follows it; hound 3.5 ignores RIFF pad bytes; lofty 0.25 misreads RF64.
